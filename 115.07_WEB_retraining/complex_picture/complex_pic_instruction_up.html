WCAG 2.2 與 WCAG 2.1 有什麼不同？

WCAG 2.2：讓操作更容易看見、更容易點選，也更容易完成。

  1. WCAG 2.2新增9項成功準則：

    • A級｜新增2項

      • 3.2.6 一致性幫助： 重複出現的協助機制，應維持一致的相對順序。
      • 3.3.7 冗餘輸入： 同一流程中已輸入的資訊，不應要求使用者再次輸入。

    • AA級｜新增4項

      • 2.4.11 焦點不遮蔽（最小）： 鍵盤焦點元件不得被作者建立的內容完全遮蔽。
      • 2.5.7 拖曳動作： 需要拖曳完成的功能，應提供不需拖曳的單一指標操作方式。
      • 2.5.8 目標尺寸（最小）： 操作目標原則上至少為24 × 24 CSS像素，或保有足夠間距。
      • 3.3.8 無障礙認證（最小）： 登入流程不得只依賴記憶、解謎或重新輸入等認知功能測試。

    • AAA級｜新增3項

      • 2.4.12 焦點不遮蔽（加強）
      • 2.4.13 焦點外觀
      • 3.3.9 無障礙認證（加強）

  2. WCAG 2.2刪除1項成功準則：

    • 4.1.1 語法分析： 因現代瀏覽器與輔助科技的處理方式已改變， WCAG 2.2將此項成功準則因過時而刪除。

  3. WCAG 2.2的四大強化重點：

    • 焦點可見
    • 操作容易
    • 表單友善
    • 認證無障礙

  4. 一句話掌握版本差異：

    WCAG 2.2延續WCAG 2.1架構，進一步強化鍵盤焦點、 拖曳替代方式、操作目標尺寸、冗餘輸入及無障礙認證。

  5. 資料來源及版本資訊：

    • 資料來源：W3C Web Accessibility Initiative（WAI）。
    • WCAG 2.2於2023年10月5日成為W3C Recommendation。

檢測方式

檢測項目：資訊圖片

  1. 確認圖片是否為複雜圖片，若非則以一般圖片方式檢測，若是則進入2。

  2. 若圖片為複雜圖片，在開啟NVDA報讀器狀態下，按下鍵盤「g」，確認報讀完整性。

  3. 若報讀可完整說明複雜圖片內容，則此項通過。

  4. 若圖片報讀不完整，則確認圖片相鄰位置是否有圖片內容說明，且說明可提供圖片內容等價資訊。

  5. 若相鄰處有提供等價說明，則此項通過。
